# Interactive High-Resolution Image Viewer

This project provides a web-based interactive viewer for very high-resolution images, allowing users to zoom and pan smoothly. Image tiles are dynamically generated by a PHP server-side script as needed.

## How to Use

1.  **Ensure Prerequisites**:
    *   A web server with PHP support is required.
    *   The PHP GD extension must be enabled on the server for image manipulation.
2.  **Place Source Images**:
    *   Put your high-resolution source images into the `public_html/zoom/sample_images/` directory.
3.  **Configure Image Path (Client-Side)**:
    *   Currently, the client-side viewer (`js/viewer.js`) is hardcoded to load `placeholder.jpg` via the `SOURCE_IMAGE_PATH` constant.
    *   To view a different image, change this constant in `js/viewer.js` to the filename of your image (e.g., `my_large_image.tif`). Ensure the image exists in `sample_images/`.
4.  **Access the Viewer**:
    *   Open `public_html/zoom/index.html` in your web browser.

## Project Structure

*   `index.html`: The main HTML page for the image viewer.
*   `tile_server.php`: The PHP script responsible for generating image tiles and providing image information.
*   `js/viewer.js`: Client-side JavaScript that handles user interaction, zoom/pan logic, and tile requests.
*   `css/style.css`: CSS styles for the viewer interface.
*   `sample_images/`: Directory to store sample high-resolution images. Contains `placeholder.jpg` and `placeholder.png` as examples.
*   `README.md`: This documentation file.

## Server-Side (`tile_server.php`)

The `tile_server.php` script is the backend engine that processes images. It is accessed via GET requests and requires the following parameters:

*   **`action`** (string, required): Specifies the operation to perform.
    *   `get_image_info`: Returns metadata about the source image.
        *   **Parameters**:
            *   `image_path` (string, required): The filename of the image within the `sample_images/` directory (e.g., `placeholder.jpg`).
        *   **Response (JSON)**:
            ```json
            {
                "width": <image_width_pixels>,
                "height": <image_height_pixels>,
                "tile_size": <server_defined_tile_size>
            }
            ```
    *   `get_tile`: Generates and returns a specific image tile.
        *   **Parameters**:
            *   `image_path` (string, required): Filename of the image in `sample_images/`.
            *   `zoom_level` (int, required): The current zoom level. Level 0 is the most detailed (where one source pixel can be magnified to fill a tile if `TILE_SIZE` is large enough, or where `TILE_SIZE` source pixels are shown per tile edge if `TILE_SIZE` is small like 1). Higher numbers mean more zoomed in (fewer source pixels per tile edge). Client `maxZoomLevel` corresponds to server `zoom_level` where 1 source pixel is rendered per tile edge pixel before scaling up to fill the tile.
            *   `tile_x` (int, required): The X-coordinate of the tile (0-indexed from left).
            *   `tile_y` (int, required): The Y-coordinate of the tile (0-indexed from top).
        *   **Response**: The raw image data (e.g., JPEG or PNG) for the requested tile. Includes `Cache-Control` headers.

*   **Security Note**: The `image_path` parameter is sanitized to only allow filenames (using `basename()`) and is restricted to accessing files within the `public_html/zoom/sample_images/` directory to prevent directory traversal attacks.

*   **Dependencies**: Requires the PHP GD extension for image processing.

## Client-Side (`js/viewer.js`)

The `js/viewer.js` script controls the front-end experience:

*   **Initialization**: Fetches image dimensions from `tile_server.php` using the `get_image_info` action.
*   **Tile Management**: Calculates which tiles are needed for the current view (based on zoom and pan) and requests them from `tile_server.php` (`get_tile` action).
*   **Zooming**:
    *   Handled via mouse wheel and on-screen buttons (+/-).
    *   Zooms towards the mouse cursor position (wheel) or viewer center (buttons).
*   **Panning**:
    *   Enabled by clicking and dragging the image.
*   **Configuration**:
    *   `SOURCE_IMAGE_PATH`: Specifies the default image to load (must exist in `sample_images/`).
    *   `TILE_SIZE`: Default is 256, but this is updated from the `tile_size` value received from `get_image_info` on the server.
